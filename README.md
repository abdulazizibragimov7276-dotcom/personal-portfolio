# Abdulaziz Portfolio

My personal portfolio website built with HTML, CSS, JavaScript, and Vite.

## Features

- About Me section
- Contact section
- Responsive design
- Social media links
- Interactive JavaScript features

## Technologies

- HTML
- CSS
- JavaScript
- Vite

## Run Locally

1. Install dependencies:

   `npm install`

2. Start the development server:

   `npm run dev`
